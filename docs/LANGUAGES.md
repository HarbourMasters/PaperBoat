# Languages (German, French, Spanish)

PaperBoat runs the US game. The European (PAL) release also contains German,
French and Spanish text and images. This optional feature builds that content
into *language packs* from **your own PAL ROM**, so the US version is left
exactly as it is unless you opt in. Nothing from the PAL ROM is stored in this
repository.

## Using it

1. Open the menu (Esc) → **Settings → General**.
2. Press **Add Languages from European ROM...** and select your European
   `Paper Mario (Europe) (En,Fr,De,Es).z64` (NUS-NMQP-EUR, big-endian `.z64`).
   The full 64 MB dump (SHA1 `2111d39265a317414d359e35a7d971c4dfa5f9e1`) and its
   trimmed 48 MB form (SHA1 `1273275142b79f7443f55bd35679a19670adfe3a`) are accepted.
3. Choose **Game Language** (Automatic follows the system language) and restart.

The packs are written to `langpacks/lang_de.o2r`, `lang_fr.o2r` and
`lang_es.o2r` next to the game (it takes a few seconds). English is always the
original US text and needs no pack. With no packs installed, or with English
selected, the game behaves exactly as before.

You can also build them without starting the game:

```
paperboat --build-language-packs <pal.z64> [pm64.o2r] [outDir]
```

## How it works

- `src/port/language/LanguagePackBuilder.*` reads the PAL ROM and the US
  `pm64.o2r` (used as the template for resource formats) and writes one pack
  per language: every message (including the 78 that only exist in PAL), the
  glyph sheet with accented letters, and the localized images (menu, pause,
  level-up, Star Points, battle and chapter text).
- `src/port/language/PalLangTables.inc` lists *where* things are (message
  names, ROM offsets, resource paths). It is generated by
  `tools/build/pal_lang_tables.py` from a papermario decomp checkout and
  contains no game data.
- `src/port/Language.*` mounts the pack for the selected language after the
  base archives and before user mods, and exposes `gGameLanguage`.
- The game keeps the US engine and its 60 FPS (NTSC) timing. PAL's 50 Hz
  compensations are intentionally not applied.

## Layout differences

PAL positions and sizes UI by language (a longer word needs a different X). The
PAL branches of the decomp that do this are applied at runtime when
`gGameLanguage` is not English, using `LANG_X(table, usValue)` and
`LANG_ADD(table, usValue)` from `include/variables.h`: for English they return
the original US value, for other languages the PAL table entry. Covered so far:
file select, pause menu (status, items, badges, partners), battle menus
(moves, star spirits, strategies), action command tips and the save block.
The file select text tables are generated by `tools/build/intl_filemenu.py`.

## Known gaps

Some screens still use English text or US layout in other languages: item
popups (use/throw away), the level-up screen in French and Spanish, the file
name entry screen, the title screen, the ImGui menus and a number of
per-language branches in map scripts.
