# Romhacks

A romhack is an overlay on top of the base vanilla game, the port extracts only what the hack changed into a small o2r file, and loads it over the base game's `pm64.o2r`. Anything the hack left alone comes from the base game.

> [!NOTE]
> Paperboat only plays romhacks it has a recipe for. Most Paper Mario romhacks carry custom code, so every
> supported romhack is reviewed and ported by hand before it's available.
